Tools I would add

These are the ones worth adding—not another huge framework.

Tool	Use in Mallan	Priority
TypeScript Compiler API	Detect forbidden provider literals, direct OData construction, improper imports/calls	P0
dependency-cruiser	Enforce module boundaries, e.g. CMA → Search allowed; CMA → Cotality forbidden	P0

fast-check is particularly valuable because it generates hundreds of input combinations and then shrinks failures to minimal reproducible examples.

For Mallan, properties should include:

stricter filter cannot increase universe

page1 ∩ page2 = ∅

union(all pages) = complete universe

count = size(complete universe)

sort changes order, never membership

save → restore preserves normalized criteria

Basic → Advanced → Basic loses zero criteria

Sale criteria never return Rental universe

Rental criteria never return Sale universe

unsupported criterion never silently broadens Search

Stryker is then useful on only the critical Search modules. It can mutate logical operators, equality, booleans, strings, arithmetic and other expressions to check whether the test suite notices.

Do not mutation-test the whole repository. Stryker allows mutation to be scoped down to individual files or even line ranges.

Dependency-cruiser can turn architectural boundaries into CI errors rather than comments. Its rule system supports forbidden, allowed and required dependencies with error severity that returns non-zero.
