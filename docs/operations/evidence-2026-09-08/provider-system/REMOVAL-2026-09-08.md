# The old provider reference system is removed (2026-09-08)

Owner ruling: **Cotality (Trestle) is the current provider and the only provider authority.** Everything follows
`Cotality raw contract → verified mapping → Mallan storage → Mallan business rules → consumers`. REBNY / RLS
remain only where they express compliance, attribution, membership or contractual requirements (UCBA rules,
required-field sets, attribution text, the `data-rls-viewer` marker the held workflow pins). Nothing REBNY-, RLS-,
RESO- or RealPlus-named is a field catalogue, an enum source, a mapping authority, a provider API or a fallback
any more — and nothing in the repository can regenerate one.
