# ⚠️ NOT THE FIELD AUTHORITY — Derived / Compatibility Data Only

The files in this directory that describe Cotality / Trestle / RLS fields are
**derived, runtime-compatibility data — NOT the field authority.** They drift
from the live feed and must never be used to validate Cotality field names,
types, or enum values:

- `rebny-rls-property-fields.csv` — REBNY IDX Plus CSV (paper spec; drifts from the feed)
- `rebny-rls-property-lookup.csv` — picklist/enum values (derived)
- `MASTER_REGISTRY.json` — generated by `scripts/generate-master-registry.js`
- `FIELD_REGISTRY.json` — CRM canonical mappings (generator input)

## The only external field authority
Cotality live `$metadata`. Refresh it **before** any field validation:

```
node scripts/get-metadata.js   # writes artifacts/metadata.xml
```

`artifacts/metadata.xml` is a *refreshed snapshot* — authoritative only
immediately after a fresh pull, never inherently live.

> A warning cannot be embedded inside the CSV/JSON files without breaking their
> parsers (`scripts/reso/drift.js`, `scripts/reso/schema-audit.js`,
> `scripts/generate-master-registry.js`), so this sibling notice marks them.
