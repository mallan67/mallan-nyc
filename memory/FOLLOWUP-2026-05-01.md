## Pre-flight checklist (run before touching any workstream)

```bash
# 1. Confirm Neon has headroom — MUST be "healthy"
npm run ops:health

# 2. Confirm no open compliance regressions
npm run ucba:audit
npm run rls:validate
npm run crm:test

# 3. If ALL pass → proceed to the workstream. Follow per-PR discipline in NEON.md §4.
```

If any of the three audits fails, **do not start any workstream.** Fix the regression first.

Each workstream below follows the same per-PR pattern from `NEON.md`:
1. Add nullable column / new table
2. Dual-write (old JSON path + new column) in `lib/idx/sync.ts` or the relevant write route
3. Wait ≥1 sync cycle (idx-sync runs `*/12 * * * *`) for backfill
4. Migrate ONE reader at a time from JSON → column
5. Verify `npm run ops:health` after each step
6. Repeat for next field / reader / route

**Forbidden:** bundling multiple columns or multiple readers into a single PR. Two changes = two rollback paths.

### Deferred (migration required — **2026-05-05 review**)

#### C1 — Inquiry model (placeholder removal)

**Evidence:** `app/api/crm/sales/listings/route.ts:60` contains the literal TODO `inquiries_count: 0, // TODO: wire when Inquiry model exists`. Frontend at `public/crm/js/dashboard/portals.js:694` renders the field. No `Inquiry` model in `prisma/schema.prisma`.

**Per-PR plan:**
1. Add `Inquiry` Prisma model: `id`, `listing_id` (FK → `Listing`), `lead_id` (FK → `Lead`, nullable for anonymous inquiries), `source` (enum: `contact_form`, `cma_request`, `open_house_rsvp`, `guide_download`, `favorite`, `search_alert`), `created_at`, `consent_captured_at`
2. Wire the 8 existing lead-capture endpoints in `app/api/` to also create an `Inquiry` row (not just a `Lead` / `Consent` row)
3. Replace `inquiries_count: 0` with `l._count?.inquiries` in `app/api/crm/sales/listings/route.ts` + the matching rentals route
4. Verify: portal dashboard shows real inquiry counts, `npm run crm:test` passes

**UCBA tie-in:** not a direct UCBA requirement, but supports UCBA Art. III §4 (data accuracy + reporting).

#### C2 — Offer tracking fields (UCBA Art. II multiple-bid disclosure)

**Evidence:** Zero matches in codebase for `offer_received_at`, `offer_submitted_to_seller_at`, `multiple_offers_disclosed`. UCBA Art. II requires brokers to disclose offers to the seller and may disclose competing bid amounts if authorized.

**Per-PR plan:**
1. Migration: add to existing `Offer` model (or create if missing): `received_at`, `transmitted_to_seller_at`, `seller_acknowledged_at`, `competing_offers_disclosed` (Boolean), `disclosure_authorized_by_seller` (Boolean)
2. Add route: `POST /api/crm/offers/[id]/transmit` — stamps `transmitted_to_seller_at`, writes `AuditEvent`
3. UI: add offer-transmission workflow to the listing agent's seller workspace in `public/crm/js/dashboard/panels/sales-crm/seller-workspace.js`
4. Reporting: expose on seller portal (sanitized DTO) so seller can verify offers were transmitted

**UCBA ref:** Art. II (multiple bids) — seller must be informed; competing-bid disclosure optional but must be consensual.

#### C3 — Auction listings support

**Evidence:** No `auction`, `auction_type`, `auction_end_date` fields in `prisma/schema.prisma`. UCBA 2026 checklist in `data/UCBA-2026-Requirements.md` calls for auction-specific fields.

**Per-PR plan:**
1. Migration: add nullable to `Listing`: `auction_yn` (Boolean), `auction_type` (enum: `Absolute`, `WithReserve`, `Minimum`), `auction_start_date`, `auction_end_date`, `auction_terms_url`
2. Form: add Auction sub-section in `public/crm/SALE-FORM-REDESIGN.html` (hidden unless `auction_yn=true`)
3. Display: conditional banner on public listing page `app/listing/[id]/page.tsx` — "This property is being sold at auction. Bidding ends [date]. [Terms]"
4. Enforcement: `lib/compliance/rls-enforcement.ts` — if `auction_yn=true` then `auction_type` + `auction_end_date` are mandatory

**UCBA ref:** Art. I (listing input rules — auction is an exception to the 24-hour price change rule; end date is substantive).

#### C4 — Ethics training gate (UCBA 2026 new requirement)

**Evidence:** No `ethics_training_completed_at` field on `Agent` model. UCBA 2026 requires ethics training before granting RLS access.

**Per-PR plan:**
1. Migration: add to `Agent`: `ethics_training_completed_at` (DateTime, nullable), `ethics_training_expires_at` (DateTime, nullable, = completed + 2 years)
2. Seed: for existing agents, broker sets the date manually via a CRM admin panel
3. Gate: `lib/auth/session.ts` — block issuing session tokens for agent role if `ethics_training_expires_at < now()`. Returns 403 with message + link to re-training resource
4. Dashboard: broker admin panel shows all agents' training status + expiry

**UCBA ref:** Art. III §6 (new 2026 — ethics training mandatory).
